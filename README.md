# Gamereview website

Deze website is gemaakt in React en is onderdeel van een Full stack webdevelopment project voor school. Dit was de eerste ervaring met het maken van een website in React.

Ik heb de keuze gemaakt om veel verschillende onderdelen toe te voegen ook meer dan nodig was voor de opdracht zelf. Dit omdat ik mezelf graag wou uitdagen om extra dingen te proberen en ik vond het ook heel leuk om te doen.

Als ik er op terug kijk ben ik erg blij met wat ik gemaakt had. Alleen had ik misschien iets meer tijd willen stoppen in de styling, want deze was uiteindelijk wel heel simpel. Ook had ik wel meer met de animaties willen proberen, omdat het niet helemaal werkte zoals ik hoopte dat het zou werken.
